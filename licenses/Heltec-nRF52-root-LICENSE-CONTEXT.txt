The current T096 compilation manifest contains 64 direct source compilation
units. The release workflow enumerates every one and classifies its file-level
notice as LGPL-2.1-or-later, MIT, BSD, Apache-2.0, or SEGGER terms. It fails
closed on an unapproved GPL-only, AGPL, unknown, or missing file-level license
classification. One SEGGER assembler source has a minimal header and is
accepted only by an exact-path and exact-content audit; its included
SEGGER_RTT.h supplies the complete governing notice, also published in the
source archive and release licenses directory.

The selected HT-n5262G variant has two additional auditable facts. Its
44-line variant.cpp is byte-for-byte identical to variants/HT-n5262/variant.cpp
at commit 7e1e40cb07452e2b43de9d1177d2d5e64ccbd8e9 from 2024-07-15, while
the repository root carried LGPL-2.1; both have SHA-256
e5265f6f9f0ad1937c0d913aeeef83be48ef30109d733344c27e4e476a55acd4.
The current variants/HT-n5262G/variant.h independently contains an explicit
LGPL-2.1-or-later file-level notice. These are recorded source-history facts,
not a conclusion that changes the terms of either file or the root LICENSE.
The release gate verifies the current variant.cpp against that exact SHA-256
and applies the semantic file-level license classifier to the
descriptor-declared variant.h. It requires exactly `LGPL-2.1-or-later` and
records the header path plus required and actual classifications in generated
provenance.

from the T096 build, link, source archive, and public object bundles.
